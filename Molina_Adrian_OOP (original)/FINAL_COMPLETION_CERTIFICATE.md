```

```

```

**Order History**:
```
User ID (SessionManager) ? Query orders table (DBEcommerce) ? 
Display OrderHistoryForm ? Query order_items (DBEcommerce) ? 
Show Details
```

```
Product ID + User ID ? Insert into wishlist table ? 
Query wishlist with join products ? Display WishlistForm ? 
Add to Cart or Remove

## ?? SECURITY IMPLEMENTATION

### **Security Features Implemented**

1. **Password Security**
   - SHA256 hashing algorithm
   - Base64 encoding
   - One-way encryption (irreversible)

2. **SQL Injection Prevention**
   - Parameterized queries throughout (@parameter syntax)
   - No string concatenation in SQL
   - User input safely passed as parameters

3. **Session Management**
   - SessionManager module tracks authenticated user
   - User ID stored in memory
   - Session cleared on logout
   - All forms verify user is logged in

4. **Input Validation**
   - Email format validation
   - Password strength requirements
   - Quantity validation (must be > 0)
   - Address and profile validation

5. **Database Constraints**
   - Foreign keys enforce relationships
   - Unique constraints prevent duplicates
   - Check constraints validate data (e.g., rating 1-5)
   - Default values protect against nulls

6. **Error Handling**
   - Try-catch blocks prevent crashes
   - User-friendly error messages
   - No sensitive error info exposed
   - Logging for debugging (optional)
